# Security Policy

## Supported Versions

Only the latest version of FestFlow is supported with security updates.

| Version | Supported |
| --- | --- |
| 1.0.x | Yes |
| < 1.0 | No |

## Reporting a Vulnerability

If you discover a security vulnerability in this project (such as leaked credentials, API key exposure, or backend flaws), please **do not open a public GitHub issue**. Instead, report it privately:

1. Send an email to **preetham.kotoju.dev@gmail.com** with the subject: `[Security Vulnerability] FestFlow`.
2. Describe the vulnerability, its potential impact, and steps to reproduce.
3. Allow up to 48 hours for a response.

## Security Practices
- All production Firebase configurations and Gemini API keys must be kept private and never committed to this repository.
- If you find any active keys in git history, please report them so they can be immediately rotated and the history purged.
