# Contributing to FestFlow

Thank you for your interest in FestFlow! Because this is a personal portfolio project, contributions are generally limited to bug reports, feedback, and documentation fixes rather than feature pull requests. 

Please read the [LICENSE](LICENSE) terms carefully before interacting with this project.

## How You Can Contribute

### 1. Reporting Bugs & Suggesting Features
If you find a bug or have a suggestion, please open an Issue:
- Clearly describe the problem and steps to reproduce.
- State your operating system, device, and Flutter version if applicable.
- For feature requests, explain the use case and why it would be beneficial.

### 2. Code Review & Suggestions
If you notice code quality issues, performance bottlenecks, or security vulnerabilities, feel free to open an issue or start a discussion. If you would like to submit a pull request:
- Open an issue first to discuss the proposed change.
- Fork the repository, create your feature branch, and submit a PR to `main`.
- Ensure all tests pass and follow Dart styling guidelines.

## Code of Conduct
Please be respectful and professional in all issues, pull requests, and discussions.
